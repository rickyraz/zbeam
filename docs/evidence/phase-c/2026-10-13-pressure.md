# OTP sender pressure and heartbeat boundary

**Decision:** keep bounded demand and explicit disconnect/reconnect semantics. A paused synchronous actor cannot indefinitely preserve the distribution heartbeat. No scheduler or runtime behavior changed in this experiment.

## Verification

Zig 0.16.0, ReleaseSafe, OTP 29/Elixir 1.20.4, four-CPU WSL2. `zig build test-all build-research-peer -j2` passed in Debug and ReleaseSafe (54 tests each). Nine serial pressure launches passed: three each at 500, 3500 and 8000 ms with OTP ticktime four seconds. Each launch generated at most 4096 × 64 KiB messages, then stopped; total offered input was bounded at 256 MiB. The native peer permits one dispatch at a time and a 2 MiB frame limit. This test intentionally allows replies to accumulate in the finite-burst sender mailbox.

At 500/3500 ms, the sender suspended around 47 submitted frames while the native handler held demand, then resumed and checked every SHA-256 result. At 8000 ms, OTP disconnected the stalled peer; a fresh connection subsequently completed a verified request. Unrelated BEAM-process probes remained responsive. The first 8000 ms run observed roughly 100.6 KiB of queued distribution output before disconnect and no unbounded increase during the pause. These finite observations are not a proof of a steady-state RSS plateau, a universal tick threshold, or a bound on arbitrary application producer queues.

`research_peer_test.exs` separately passed test-owned injected allocation failure, panic and noncooperative spin. Faults are startup-only options in the optional developer executable; production wire messages cannot trigger them. Spin cleanup sends SIGKILL only to the OS PID retrieved from the test's own Port. Core dumps were disabled for these probes.

## Reproduce

```sh
zig build test-all build-research-peer -j2 -Doptimize=ReleaseSafe
epmd -daemon
ERL_FLAGS='+S 2:2 +SDcpu 2 +SDio 1' elixir --name pressure@127.0.0.1 \
  --cookie research_cookie benchmarks/beam_pressure.exs \
  "$PWD/zig-out/bin/zbeam-research-peer" 8000
ulimit -c 0
ERL_FLAGS='+S 2:2 +SDcpu 2 +SDio 1' elixir --name faults@127.0.0.1 \
  --cookie research_cookie benchmarks/research_peer_test.exs \
  "$PWD/zig-out/bin/zbeam-research-peer"
```

Raw output and build logs: `2026-10-13-pressure/`. Repeat the pause command with 500/3500 ms and unique VM names. These scripts require the host Elixir JSON module and were not run under OTP 25–27; baseline wire conformance remains unchanged. Native Linux replication, kernel queue/RSS accounting, long-running producer policies, and multi-actor heartbeat service remain open. The experiment does not remove deadline/demand gates to preserve liveness artificially.
