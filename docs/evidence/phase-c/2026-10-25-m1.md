The integrated regression covers bad cookies, partial/silent handshakes, partial
frames, blocked replies, cancellation, positive-demand admission, next-peer
recovery and registration loss. A nonreturning CPU handler is not preempted.
Pausing demand also pauses ticks; a sufficiently long pause may disconnect the
peer. No speculative reads, hidden queue or unlimited-pause guarantee is added.

W0 is verified. Later M1 increments require their own tests; these results do not
establish process monitors, actor-local panic isolation or production deployment.

## W3 — Single-worker identity and correlated requests

`test-all` passed 62/62 in both [Debug](2026-10-25-m1/w3-debug.log) and
[ReleaseSafe](2026-10-25-m1/w3-release.log), using the same Zig 0.16.0 and host.
The [pinned OTP matrix](2026-10-25-m1/w3-otp.log) passed 25/26/27 for legacy
services and the new worker profile. Commands are W0's commands, rerun on W3.

The new smoke checks discovery, exact empty/3-byte/1-MiB hashes, bad-request
handling, a mutated stale PID, identity preservation on TCP reconnect and normal
stop with node survival. Unit tests sweep allocation failures through discovery,
hash, stop and reply decoding; fixed test output storage avoids conflating writer
allocation failure with codec allocation errors. Monitor flags are still off.

PID generation uses EPMD creation plus a random ID/serial. This is not an absolute
persistent identity guarantee after EPMD state loss. No native scheduler, queued
payload lifetime or automatic worker restart is inferred from these tests.
