## Inspected constraints

| Source | Observation used in the proposal |
|---|---|
| `src/zbeam/runtime/actors.zig` | Registry owns names/maps, not tasks/storage; send resolves then unlocks; deinit requires caller-joined users |
| `src/zbeam/actor/mailbox.zig` | Fixed caller buffer, blocking put, logical/copyable receive token; no nested-payload destruction |
| `src/zbeam/runtime/node.zig`, `worker.zig` | Synchronous M1 frame lifetime and peer-owned canonical monitor slices cannot be handed to independent tasks unchanged |
| `src/zbeam/transport/deadline.zig` | Select cancellation joins losers before borrowed arguments are freed; not a hard deadline on noncooperative CPU work |
| Installed Zig 0.17 `lib/std/Io.zig` | `Future.cancel/await` are joining, non-threadsafe operations; `Group` is whole-group; `concurrent` can fail, `async` may execute inline |
| Same file, `TypeErasedQueue` and `Queue.put` | `min = 0` avoids waiting for capacity; an error from `put` transfers no elements; close does not destroy elements or quiesce old blocked putters |
