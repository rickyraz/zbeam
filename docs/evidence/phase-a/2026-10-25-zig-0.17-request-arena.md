# Request-local arena on Zig 0.17

Source: `explore/request-arena` at `ff5ac17`; shared parent `27b0fee`.
The tested standard-allocator compiler migration `3bec5e3` is merged without
adding another allocator feature. Linux x86-64 WSL2; no NIF comparison source.

- Explicit 0.16 SMP/1 MiB-retain core and allocator baseline: **36/36 steps,
  55/55 tests**.
- 0.17 default `test-all test-labs test-allocators`: **69/69 steps** in debug/safe.
- All five standard allocator/libc controls pass seven allocator/workload tests
  with 1 MiB retain in each mode. This includes allocation-failure cleanup,
  warmed reuse/zero-retention, over-aligned realloc, paused/canceled ownership
  and bounded cross-thread handoff (a deliberate no-arena negative control).
- SMP policies off/free-all/1 MiB retain pass core plus allocator tests in both
  modes and build into three separate safe prefixes. Failed retain-resize falls
  back to free-all; tests exercise current owned packet/response paths. Arbitrary
  custom-handler lifetime escapes are not statically prevented.
- Each policy passes the pinned OTP 25/26/27 safe matrix: **8/8 steps per policy**.
- All three argument-forwarding checks, formatting and CI YAML checks pass.

Compressed raw logs and three-prefix/compiler hashes are in
`2026-10-25-zig-0.17/request-arena-*.log.gz`.

branch; no lifetime workaround was needed for 0.17. Current recipes use `safe`.
Standard allocator deprecation/default-policy caveats are inherited unchanged.
