# Canonical Zig 0.17 migration

**Date:** 2026-10-25. **Source:** remote master `497d346` (accepted labs included).
**Worktree:** isolated `migrate/zig-0.17-master`; original worktrees unchanged.
**Environment:** Linux x86-64 WSL2, Zig 0.17.0; OTP 25/26/27 pinned Docker images.

## Result and change boundary

The canonical MVP and labs compile and pass on 0.17. No M1 runtime, allocator
experiment, protocol extension or scheduling change is promoted by this commit.
The original 0.16 baseline passed 63/63 build steps and 69/69 tests (47 core,
22 labs), including the two intentional compile failures.

Migration changes are limited to `Run.addPassthruArgs`, typed `@splat` instead of
the removed array repetition syntax, and current toolchain/CI instructions.
0.17's optimizer names are `debug`, `safe`, `fast`, `small`; `ReleaseSafe` is not
a valid 0.17 option. Historical logs/design pseudocode retain their old labels.
`scripts/test/build_args_smoke.sh` tests both run/benchmark forwarding with isolated
benchmark tool stubs, without requiring Elixir or touching a live EPMD daemon.

## Allocator and artifact provenance

`master-017-provenance.log.gz` records compiler/startup-source/executable SHA-256,
ELF linkage and allocator symbols for the safe binary. In this installed 0.17
`lib/std/start.zig`, `use_safe_allocator` is true in debug/safe, and
`std.process.Init.gpa` selects `std.heap.SafeAllocator`, including libc-linked
builds. The 0.16 DebugAllocator audit is not reused as current evidence.
No latency/RSS result or new allocator winner is inferred.

CI pins and package minimum now require 0.17.0. The passing native matrix does
not establish Zigler, snmalloc ABI or all-branch completion; those are separate
branch gates. Promotion must retain the immutable pre-migration archive tags and
must not move a branch behind another session's checked-out worktree.
