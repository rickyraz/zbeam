## Black-box assertions

Every target VM:

1. Receives exact replies for atoms, signed i32 boundaries, empty tuples/lists, proper lists, a PID-containing tuple and a 64 KiB binary.
2. Verifies an unknown registered name does not prevent a subsequent valid reply.
3. Remains connected over a five-second idle interval with OTP `net_ticktime=4`, then receives another reply.
4. Rejects a wrong-cookie connection without terminating the service.
5. Disconnects and reconnects to the same service process.
6. Sends an unsupported map, observes disconnect, reconnects and gets a valid reply.
7. Monitors the node while the shell kills only its own zbeam child with SIGKILL; observes nodedown within three seconds, an unchanged OTP OS PID and an unrelated responsive local process.
8. Observes EPMD registration removal after the child exits.
9. Runs an OTP registered echo process while zbeam looks it up, initiates a handshake, validates peer identity and receives its exact PID-addressed reply.

The runner uses exact Erlang assertions, not success inferred from log substrings. Registration/readiness and external commands have bounded waits.

## Reproduced regressions

- **EPMD error overread:** a two-byte `PORT2_RESP` error incorrectly produced `EndOfStream` because the client first demanded the success layout. The deterministic socket regression failed with that exact mismatch, then passed after reading tag/result first.
- **Handshake handoff data loss:** coalescing the final handshake message with a tick lost the tick in a discarded read-ahead buffer. Both roles now use unbuffered handshake readers and preserve those bytes.
- **Initiating reply routing:** real OTP sent a four-field `REG_SEND` housekeeping message before the three-field `SEND` reply. The probe now validates and ignores unrelated registered messages; a synthetic socket peer protects this sequence, including a tick.
- **Redirected stdout overwrite:** positional file writers overwrote the beginning of shared redirected logs. `cli_smoke.sh` failed before the fix. Both CLI writers now use streaming mode; raw records above were regenerated after the fix.
- **Environment-dependent integration gate:** the old integration suite waited on an absent external EPMD daemon and failed with `Timeout`. Core integration now uses a deterministic socket peer; real registration lifecycle remains checked by the external matrix.

## Limits

Golden ETF and structural wire fixtures remain provenance-labeled; they are not a new packet-capture campaign. The matrix does not test every OTP patch, platform, ETF tag or distribution capability. Atom caches, fragment assembly, process links/monitors, simultaneous-connection arbitration, proactive heartbeat policy, TLS and deadlines remain unimplemented. SIGKILL is not a panic/corruption proof.

CI wiring requires the selected OTP version and runs Debug/ReleaseSafe deterministic gates. Hosted CI execution is not claimed by these local results.
