# Independent M2b distribution vectors — 2026-10-28

Thirteen fixed pass-through distribution frames were generated with the OTP ETF
encoder, not zbeam's encoder. They cover discovery for both workers, hash to
both, stop, PID/digest/error/stop replies, PID monitor/demonitor, named monitor
and normal monitor exit. Fixed synthetic node/PID/reference bytes establish the
same input identities; `term_to_binary(...,[{minor_version,2}])` generates ETF
and the script assembles the documented framing.

  OTP 25, 26 and 27 Docker images named by `otp_docker_matrix.sh`, without
  network access. The three outputs compare byte-for-byte and have SHA-256
  `325a86cfbac8c5d6c3547f44a49fc269c7f6cdc25ba86de258ca513bf2a5053f`.
- Zig 0.17.0 on Linux/WSL: `zig build test-conformance -Doptimize=debug -j2
  --summary all` and the same command with `safe`: 3/3 steps, 9/9 tests in each.
  The new test constructs expected controls/payloads, compares every full frame
  exactly and independently decodes each fixture.

The vectors use deterministic synthetic identities, not captured production
traffic, and do not prove handshake, arbitrary ETF, overload or recovery. Actual
OTP process integration is recorded separately. Roll back the generator, fixture,
